# Rivo

Connect. Share. Discover.

### A modern social media experience.

A clean, modern and responsive social media web application inspired by platforms like X (Twitter), built as the final project of the Front-End Bootcamp.

---

## ✨ Features

- 🔐 Login & Register
- 🏠 Home / Feed
- ❤️ Like Posts
- 💬 Comment on Posts
- 🔔 Notifications
- 👤 User Profiles
- 👥 Follow Users
- 🌙 Light & Dark Mode
- 📱 Fully Responsive
- 🎨 Modern UI
- ⚡ Reusable Components

---

## 🛠 Tech Stack

| Technology | Usage |
|------------|-------|
| React | UI |
| TypeScript | Type Safety |
| Vite | Build Tool |
| CSS | Styling |
| Git | Version Control |

---

## 🚀 Getting Started

Clone the project:

```bash
git clone <repository-url>
```

Go to the project directory:

```bash
cd Rivo
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

---

## 🎨 Design

Rivo follows a clean and minimal design system based on the provided Figma design.

The project supports:

- 🌓 Light & Dark Theme

- 🎨 Centralized Design Tokens
- 🧩 Reusable UI Components
