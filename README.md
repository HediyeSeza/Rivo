# Rivo

Connect. Share. Discover.

### A modern social media experience.

A clean, modern and responsive social media web application inspired by platforms like X (Twitter), built as the final project of the Front-End Bootcamp.

---

## ✨ Features

- 🔐 Login & Register
- 🏠 Home / Feed
- ❤️ Like Posts
- 💬 Comment on Posts
- 🔔 Notifications
- 👤 User Profiles
- 👥 Follow Users
- 🌙 Light & Dark Mode
- 📱 Fully Responsive
- 🎨 Modern UI
- ⚡ Reusable Components
